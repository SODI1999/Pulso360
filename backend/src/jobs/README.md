# P09 · Jobs — Procesador y Planificador de Tareas

## 1. Identificación del Componente
* **Paquete Arquitectónico**: `P09 · jobs`
* **Componentes C4**: `C06 · Procesador de tareas` y `C12 · Planificador de tareas`
* **Naturaleza**: Procesamiento en segundo plano y tareas programadas.

---

## 2. Responsabilidades
1. **Evaluación de Reglas de Alerta**: Evaluar de forma periódica si una campaña o equipo presenta caídas sostenidas de recuperación o sobrecarga emocional agregada durante varias semanas consecutivas.
2. **Generación de Alertas Preventivas**: Insertar en la tabla `sst_alerts` cuando se cumpla una condición de umbral.
3. **Análisis Léxico Diferido**: Procesamiento de textos de bitácora mediante el motor determinista local para clasificar categorías sin bloquear la respuesta HTTP al usuario.
